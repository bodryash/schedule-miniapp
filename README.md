# Расписание ФГП МГУ — Telegram Mini App

Мини-приложение показывает расписание занятий: студент один раз выбирает
группу, дальше сразу видит свой день.

Открыто по адресу <https://bodryash.github.io/schedule-miniapp/>.

## Из чего состоит

| Что | Где |
| --- | --- |
| Страница мини-приложения | `docs/` — статика, без сборки |
| Данные расписания | `docs/data/schedule.json` |
| Парсер PDF | `tools/parse_pdf.py` |
| Бот на вебхуке (боевой) | `worker/` — Cloudflare Worker |
| Бот на опросе (локальный) | `bot.py` |

## Обновить расписание

```bash
python tools/parse_pdf.py "путь/к/расписанию.pdf"
```

Перезаписывает `docs/data/schedule.json`. После этого закоммитить и запушить —
GitHub Pages раздаёт папку `docs/` с ветки `main`.

## Запустить локально

```bash
python -m http.server 8123 --directory docs
```

## Бот

Боевой бот живёт в Cloudflare Worker и работает без включённого
компьютера: Telegram сам шлёт обновления на вебхук.

- Бот: [@FGPshedulebot](https://t.me/FGPshedulebot)
- Воркер: <https://fgp-schedule-bot.bodryash.workers.dev>

Разворачивается из папки `worker/`:

```bash
npx wrangler deploy
```

Токен и секрет вебхука в файлах не лежат — они задаются один раз:

```bash
npx wrangler secret put BOT_TOKEN
```

```bash
npx wrangler secret put WEBHOOK_SECRET
```

Секрет вебхука Telegram присылает в заголовке `X-Telegram-Bot-Api-Secret-Token`.
Без этой проверки на публичный адрес воркера мог бы слать поддельные
обновления кто угодно.

Локальный `bot.py` остаётся для отладки, но **одновременно с вебхуком он не
работает**: Telegram отдаёт обновления либо туда, либо сюда. Чтобы вернуться к
опросу, вебхук надо удалить (`deleteWebhook`), и наоборот. Для `bot.py` нужен
`.env` с `BOT_TOKEN`.

## Формат данных

`schedule.json`:

- `meta` — семестр, факультет, даты начала и конца.
- `weeks` — календарь чётных и нечётных недель из примечания к расписанию.
  Чётность берётся отсюда, а не считается по формуле: первая неделя семестра
  укорочена, и арифметика по номеру недели даёт неверный ответ.
- `bells` — время пар.
- `groups` — `id`, `title`, `course`.
- `lessons` — по одной записи на пару и группу:
  `group`, `day` (1 = понедельник), `slot`, `week` (`all` / `odd` / `even`),
  `subject`, `type`, `teacher`, `room`, `subgroup`, `elective`
  (`null`, `«по выбору»`, `«факультатив»`), `note`.

## Настройки студента

При первом запуске приложение спрашивает курс, группу, основной язык с
подгруппой и второй (или третий) язык с подгруппой.

Основной язык — это либо английский, либо русский для иностранцев; вместе они
не встречаются, поэтому спрашиваются одним вопросом. Названия зависят от
курса: на младших «Английский язык» и «Русский язык как иностранный», на
старших «Профессиональный английский» и «Профессиональный русский».

Списки строятся по самим данным: для 1 курса второго языка нет, и поле не
показывается; если подгруппа всего одна, вопрос тоже пропускается. Ответы
лежат в `localStorage` под ключом `schedule.prefs`.

Последним блоком идут галочки дисциплин по выбору — список строится по парам
самой группы. Отмеченные останутся в расписании, остальные скроются. Если не
отмечено ничего, показываются все: иначе студент, пропустивший этот блок,
получил бы расписание без половины занятий.

Дальше языковые пары чужих подгрупп скрыты.

## Цвета занятий

- Зелёный — дисциплина по выбору.
- Фиолетовый — межфакультетский курс МГУ.

Эти цвета говорят про тип занятия, поэтому не зависят от чётности недели и не
меняются вместе с акцентом.

## Окна

Свободная пара между занятыми показывается отдельной строкой «ОКНО» с номером
пары и временем. Пустые пары в начале и в конце дня окнами не считаются.

## Календарь

Сверху стоит дата выбранного дня. Полоса дней тянется на две недели —
текущую и следующую — и листается вбок; недели разделены чертой, сегодняшнее
число подсвечено акцентом, даже когда пролистали на другой день. Дальше двух
недель не идём: расписание на послезавтра нужно часто, на месяц вперёд — нет.

Приложение открывается на сегодняшнем дне. В воскресенье занятий нет, поэтому
показывается понедельник уже следующей недели, а не той, что закончилась, и
полоса начинается с него.

Чётность считается по неделе целиком, а не по конкретному дню: иначе
понедельник 31.08 выпал бы из семестра, начатого 02.09, и подпись недели
менялась бы при переключении дней.

## Текущая пара

Идущая пара определяется по часам телефона и подсвечивается акцентом: точка,
подпись «идёт сейчас», сколько осталось до конца и полоса прогресса по низу
карточки. При открытии приложение подводит к ней, если она не попала на экран.

Полоса — WAAPI-анимация длиной во всю пару: идёт на компоновщике, как
CSS-анимация, но её позицию можно выставить по часам. Это важно: таймлайн
анимаций останавливается, пока приложение свёрнуто, и CSS-вариант после
возвращения показывал бы момент, на котором его прервали. Поэтому позиция
сверяется с часами на каждом обновлении и при возврате в приложение
(`visibilitychange`), а между сверками анимация идёт сама.

Текст «осталось N мин» обновляется там же, раз в 30 секунд, поверх готовых
карточек: перерисовка списка заново проигрывала бы появление каждые полминуты.

Всё время берётся с устройства — часовой пояс и часы телефона. Звонки в PDF
московские, так что телефон в другом поясе покажет «идёт сейчас» не ту пару.
Если приложение оставили открытым до следующего дня, страница перезагружается —
точечного обновления там уже мало.

## Движение

- Смена дня — появление карточек за 180 мс с каскадом по 25 мс, ограниченным
  120 мс: список в длинный день не должен ждать свою анимацию дольше, чем
  читается. Пришли листанием — карточки въезжают с той стороны, откуда тянули.
- Листание дней — расписание ведётся за пальцем. День меняется, если
  протянули больше 22% ширины экрана **или** сделали быстрый флик; иначе
  возвращается на место. На краях ленты сопротивление растёт, но упора нет.
  Направление жеста определяется по первым 8 пикселям: если движение скорее
  вертикальное, жест отдаётся прокрутке (`touch-action: pan-y`).

  Жест слушает весь экран расписания, а не список пар: в субботу у первого
  курса пар нет вовсе, и на списке из одной строчки «Пар нет» тянуть было бы
  не за что. Полоса дней и кнопки из жеста исключены — им горизонталь нужна
  самим.
- Переход между расписанием и настройками — 200 мс.
- Нажатие — сжатие до 0.97 за 120 мс.

Всё держится на `transform` и `opacity`. При `prefers-reduced-motion` движение
убирается, а смысловые появления остаются как проявление прозрачности.

## Цвет недели

Нечётная неделя — голубой интерфейс, чётная — оранжевый. Переключается
атрибутом `data-parity` на `<body>`; вне семестра берётся акцент темы
Telegram.

## Известные ограничения

- Аудитория пустая там, где её нет в самом PDF.
- Третьи языки (`3-ий Немецкий`, `3-ий Японский`) идут факультативами без
  подгрупп, поэтому показываются всем, пока не выбраны явно.
- «Военная подготовка» занимает подряд несколько пар, из-за чего окон в эти
  дни не остаётся.
- Разбор рассчитан на вёрстку расписания ФГП. Другой факультет потребует
  правок в `tools/parse_pdf.py`.
