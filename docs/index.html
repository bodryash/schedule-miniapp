Мои МФК

Курсы берутся из личного кабинета МГУ. Выбранные встанут в расписание со своим временем и аудиторией.

Дисциплины по выбору

Если не отмечено ничего, показываются все.

Тогда расписание будет открываться с рабочего стола, минуя Telegram.

Дальше на айфоне:

  1. Откройте Safari и вставьте адрес
  2. Кнопка «Поделиться» → «На экран «Домой»

Telegram на айфоне ярлыки создавать не умеет — это ограничение iOS.
